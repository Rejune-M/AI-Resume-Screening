AI Resume Screening

I created this project in order to make the process of screening resumes and matching people with jobs a bit easier.

The program accepts a CV and a job advertisement, analyzes the information contained in them, and checks the extent to which the candidate's skills and experience correspond to the job's requirements. It also provides a score in the style of an ATS and highlights any missing skills or keywords that could be improved.

What it does

* Upload a resume and analyze it
* Compare the resume with a job description
* Find matching skills and keywords
* Generate an ATS-style match score
* Show missing or important skills
* Give suggestions to improve the resume
* Simple and interactive web interface

Technologies Used

* Python
* Streamlit
* NLP
* Machine Learning
* PDF/Text Processing

Why I built it

I wanted to find out how a resume could fare when compared with a particular job description, so I developed this project in order to carry out some experimentation with resume analysis, NLP, and AI-driven job matching at the same time as producing a useful outcome for real-world use.
